1. INTRODUCTION                                     *md-preview-introduction*

nvim-md-preview renders the current Markdown buffer in your browser and keeps
it in sync as you type. A single Rust binary converts Markdown to HTML and
serves the page on 127.0.0.1; Mermaid, KaTeX, highlight.js and fonts are
embedded, so it works offline and needs no Node.js.

The preview scrolls with the cursor block by block. Clicking a paragraph in
the preview moves the cursor to that line, and clicking a local `.md` link or
a wiki link opens that file in Neovim.

==============================================================================
2. INSTALLATION                                     *md-preview-installation*

Install the plugin with your plugin manager, then run |:MdPreviewInstall|.
With lazy.nvim: >lua
    {
      "ywsrock/nvim-md-preview",
      build = ":MdPreviewInstall",
      config = function() require("md_preview").setup({}) end,
    }
<
Files are stored in `stdpath("data")/nvim-md-preview/`.

Run `:checkhealth md_preview` to check the binary, pandoc, Typst, download
tools and how the browser is opened.

3. COMMANDS                                             *md-preview-commands*

:MarkdownPreview                                          *:MarkdownPreview*
:MdPreview                                                      *:MdPreview*
    Start the preview for the current Markdown buffer. Downloads the binary
    first if it is missing.

:MarkdownPreviewStop                                  *:MarkdownPreviewStop*
:MdPreviewStop                                              *:MdPreviewStop*
    Stop the preview server.

:MarkdownPreviewToggle                              *:MarkdownPreviewToggle*
    Start or stop the preview.

:MdPreviewExport {format} [{path}]                        *:MdPreviewExport*
    Export the buffer being previewed, including unsaved changes. {format}
    is one of `pdf`, `slides`, `docx`, `html`, `epub`, `markdown`. `slides`
    writes a PDF with one slide per page (see |md-preview-export-config|
    `slide_size`). Without {path} the file is written next to the source
    with the new extension (`markdown` uses `{name}.export.md`, `slides`
    uses `{name}.slides.pdf`). Exporting onto the file being edited is
    refused. The preview must be running.

:MdPreviewDiff [{base}]                                     *:MdPreviewDiff*
    Without an argument, toggle |md-preview-git_diff|. With {base} (`HEAD`,
    `staged`, a branch, tag or commit), compare against it and turn the diff
    on. `off` turns it off. Completes branch and tag names.

    Changed paragraphs show inserted words underlined and removed words
    struck through. Removed paragraphs, and the previous version of changed
    code, tables, diagrams and math, appear as collapsed boxes. The page
    header shows the number of changes with buttons to jump between them,
    and markers beside the scrollbar show where they are.

:MdPreviewInstall                                        *:MdPreviewInstall*
    Download the preview binary, pandoc and Typst in parallel. Progress is
    shown on the command line and a summary is shown when done.

:MdPreviewInfo [copy]                                      *:MdPreviewInfo*
    Show the preview URL, the file being previewed, the Git diff base, and
    which tools are used for PDF and PlantUML. With `copy`, copy the URL to
    the clipboard (`+` register) and the unnamed register.

4. CONFIGURATION                                   *md-preview-configuration*

Call `require("md_preview").setup(opts)`. All keys are optional; defaults:

    filetypes                                        *md-preview-filetypes*
        `{ "*" }`. File types (|'filetype'|) that can be previewed; `"*"`
        means every file. Markdown, vimwiki, Quarto, R Markdown, pandoc
        and MDX are rendered as documents; other files are shown as
        highlighted code with line numbers. Buffers with a 'buftype'
        (help, file explorers, terminals) are never previewed.

    max_file_size                                *md-preview-max_file_size*
        `2097152` (2 MB). Larger files are not previewed. Binary files are
        never previewed.

    port                                                  *md-preview-port*
        `9876`. If it is taken, the next free port is used.

    host                                                  *md-preview-host*
        `"127.0.0.1"`. Set `"0.0.0.0"` for |md-preview-lan|.

    auto_open                                        *md-preview-auto_open*
        `true`. Open the browser when the preview starts.

    browser_app                                    *md-preview-browser_app*
        `false`. Open the preview in an app window without tabs or an
        address bar (`--app` of Chrome, Edge, Brave or Chromium). Uses
        `export.browser_path`, or finds one of those browsers (on WSL, the
        Windows one). Without one, the default browser is used.

    scroll_sync                                    *md-preview-scroll_sync*
        `true`. Scroll the preview with the cursor.

    cursor_highlight                          *md-preview-cursor_highlight*
        `true`. Outline the block under the cursor in the preview: the
        paragraph, heading, list item, table or code block, or the line in
        code files. Works with `scroll_sync = false` too. Style it with
        `.cursor-block` in |md-preview-custom_css|.

    follow_buffer                                *md-preview-follow_buffer*
        `true`. Switch the preview when you enter another Markdown buffer.

    debounce_ms                                    *md-preview-debounce_ms*
        `80`. Milliseconds to wait after typing before updating.

    theme                                                *md-preview-theme*
        `"auto"`, `"dark"` or `"light"`. "auto" follows the OS. Toggling the
        theme in the browser is remembered and takes precedence.

    custom_css                                      *md-preview-custom_css*
        `""`. Path to a CSS file loaded after the built-in styles.

    wiki_links                                      *md-preview-wiki_links*
        `true`. Render `[[Page]]` and `[[Page|label]]` as links. `.md` is
        added when the target has no extension.

    task_toggle                                    *md-preview-task_toggle*
        `true`. Click a task list checkbox (`- [ ]`) in the preview to toggle
        it in the buffer, as one change that can be undone. If the preview
        is behind the buffer (for example right after typing), nothing is
        changed and a message asks you to try again. Not available in LAN
        mode (|md-preview-host| other than localhost).

    browser_keys                                  *md-preview-browser_keys*
        `true`. Keyboard shortcuts in the preview page: `t`, `/`, CTRL-F and
        `p` (see |md-preview-keys|). Set `false` when they clash with a
        Vim-style browser extension such as Vimium or Tridactyl; the
        toolbar buttons keep working.

    git_diff                                          *md-preview-git_diff*
        `true`. Show Git changes in the preview. Toggle with
        |:MdPreviewDiff|. Files outside a Git repository show nothing.

    git_diff_base                                *md-preview-git_diff_base*
        `"HEAD"`. What to compare against: `"HEAD"`, `"staged"` (the index),
        or a branch, tag or commit. A file missing from {base} is shown as
        entirely added; an unknown {base} shows a warning.

    git_diff_colors                            *md-preview-git_diff_colors*
        `true`. Use the editor's diff colors (`GitSignsAdd`, `Added`,
        `DiffAdd`, ...). Colors that are hard to read on the preview's theme
        fall back to the defaults.

    plantuml_path                                *md-preview-plantuml_path*
        `""`. The `plantuml` command, or a `plantuml.jar` run with
        `java -jar`, used to draw ```plantuml and ```puml blocks. Empty uses
        `plantuml` on `PATH`. Without it, the blocks are shown as code.

    plantuml_server                            *md-preview-plantuml_server*
        `""`. A PlantUML server URL, for example
        `"https://www.plantuml.com/plantuml"`. When set, the browser loads
        the diagrams from this server instead of running `plantuml`, so the
        diagram sources are sent to it. Empty never uses a server.

    binary                                              *md-preview-binary*
        Path to the preview binary. Defaults to the downloaded copy.

    log_file                                          *md-preview-log_file*
        `""`. File to append a log to: start and stop, the port, the tools
        used, export results and errors from the binary. Document contents
        are never written and the LAN token is masked. Empty writes nothing.

    export                                       *md-preview-export-config*
        See |md-preview-export|.

Vimscript: `g:md_preview_port` and `g:md_preview_auto_open` are also read.

5. BROWSER KEYS                                             *md-preview-keys*

    t               Toggle the table of contents.
    / or CTRL-F     Search. <Enter> / <S-Enter> next / previous, <Esc> close.
    p               Presentation mode. Slides are split on `---`, or on h1/h2
                    when there is none. Arrow keys move, `f` fullscreen,
                    <Esc> exits. The slide follows the editor cursor.
    click           Jump to that line in Neovim.

`t`, `/`, CTRL-F and `p` are disabled when |md-preview-browser_keys| is
`false`. Vim-style browser extensions (Vimium, Tridactyl, Surfingkeys) use
the same keys and usually receive them first. Either set `browser_keys =
false` and use the toolbar buttons, or exclude `http://127.0.0.1:*/*` in the
extension (Vimium: excluded URLs, Tridactyl: `:blacklistadd 127.0.0.1`).

The print button shows the page on an A4 sheet with page-break guides; press
it again to print.

6. EXPORT                                                *md-preview-export*

PDF uses Typst, DOCX / HTML / EPUB use pandoc. Both are downloaded by
|:MdPreviewInstall|. Options under `export`:

    formats         `{ "pdf", "slides", "docx", "html", "epub", "markdown" }`. Formats
                    offered in the preview's Export menu and in
                    |:MdPreviewExport| completion. `{}` hides the Export
                    button.
    pdf_engine      `"browser"`. Print the preview with Chrome, Edge, Brave or
                    Chromium, so the PDF looks like the preview. Without
                    one of them, Typst is used. `"typst"` always uses Typst
                    (supports `template`; Mermaid, math and callouts are not
                    rendered).
    browser_path    `""`. Browser for PDFs. Empty looks for Chrome, Edge,
                    Brave and Chromium in their usual places and on PATH.
    docx_engine     `"pandoc"`. Any other value skips downloading pandoc.
    pandoc_path     `""`. Empty: downloaded copy, then `pandoc` on PATH.
    typst_path      `""`. Empty: downloaded copy, then `typst` on PATH.
    paper           `"a4"`. Any Typst paper name, e.g. `"us-letter"`.
    margin          `"2cm"`.
    font            `""`. Empty: Noto Serif CJK JP with fallbacks.
    font_size       `11` (pt).
    toc             `false`. Add a table of contents (PDF and pandoc).
    numbering       `false`. Number headings (PDF and pandoc).
    slide_size      `"16:9"` or `"4:3"`. Page shape of `slides`. Slides are
                    printed with a Chromium browser whatever `pdf_engine`
                    is; a slide too long for a page is scaled down.
    template        `""`. With `pdf_engine = "typst"`, a Typst file exporting
                    `template`, applied as a show rule:
>typst
    #let template(doc) = {
      set page(header: align(right)[Internal])
      doc
    }
<
Relative image paths are resolved from the document's directory.

==============================================================================
7. LAN MODE                                                  *md-preview-lan*

With `host = "0.0.0.0"` the server listens on all interfaces so you can open
the preview from a tablet or another computer. A random token is generated
every time the preview starts and the LAN URLs are shown in Neovim. Requests
without the token are rejected; a browser that opened the URL once keeps a
cookie for the session.

In the default localhost mode the server rejects requests whose Host is not
a loopback name and any cross-origin request or WebSocket.

8. LUA API                                                   *md-preview-api*

    require("md_preview").setup({opts})       Configure the plugin.
    require("md_preview").start()             Same as |:MarkdownPreview|.
    require("md_preview").stop()              Same as |:MarkdownPreviewStop|.
    require("md_preview").export({fmt}, {path}) Same as |:MdPreviewExport|.
    require("md_preview").toggle_diff({base}) Same as |:MdPreviewDiff|.
    require("md_preview").install({opts})     Same as |:MdPreviewInstall|.
        {opts}.missing_only  download only files that are missing
        {opts}.on_done       function(ok) called when finished

9. TROUBLESHOOTING                               *md-preview-troubleshooting*

Run `:checkhealth md_preview` first.

The browser does not open ~
    Open the URL shown in the message manually, or set `auto_open = false`.
    On WSL, install `wslu` for `wslview`.

Export fails ~
    Make sure pandoc or Typst is installed (|:MdPreviewInstall|). PDF export
    downloads the `cmarker` Typst package on first use, which needs network
    access once.

Nothing updates ~
    Check that the status dot in the page header is green. Restart with
    |:MdPreviewStop| and |:MdPreview|.
